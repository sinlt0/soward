## What you get

- Higher ticket limits: 10 panels, 20 staff roles per panel and more categories and questions
- No-prefix mode, so members can run commands without typing the prefix
- Higher limits on other features as they are added

## Activate a key

If you were given a premium key, run this in your server:

```
!premium claim <key>
```

Run `!premium` to see the current status and expiry.

## Notes

Premium is granted for a set time or permanently. The bot does not take payments. Keys are issued by the bot team.
