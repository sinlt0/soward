## Add the bot

Use the **Add to server** button on the site. Grant the permissions it asks for. Moderation, tickets and verification need Manage Roles, Manage Channels, Ban Members and Kick Members.

Place the bot's role **above** any role it needs to give or remove.

## Use commands

The bot uses a prefix. The default is `!`, so `!help` opens the help menu. Change it any time:

```
!prefix ?
```

You can also change it from the dashboard under **Server settings**.

## Good first steps

1. Run `!help` and browse the categories.
2. Run `!logging setup` to create a log category with a channel per event group.
3. Run `!automod enable` and add a few banned words with `!automod banword <word>`.
4. Run `!ticket panel create` to build your first support panel.
5. Open the dashboard and look through the module list.

## Getting help

Every command has a usage line. Type `!help <command>` to see it, or check the [commands page](/commands).
